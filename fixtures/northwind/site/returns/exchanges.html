Exchanging an item

If you want a different size or color of the same product, you can request an exchange instead of a return within 30 days of delivery. Exchanges ship free by Standard Ground.

How exchanges work

Start a return from your Orders page and choose Exchange as the reason. Pick the replacement item, and we ship it as soon as the carrier scans your return label, so you do not have to wait for the original to reach us.

Price differences

If the replacement costs more, we charge the difference to your original payment method. If it costs less, we refund the difference.

Exchanges are limited to the same product. To switch to a different product, return the original and place a new order.
